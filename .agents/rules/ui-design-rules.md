# Aturan Desain Web ORIA (UI/UX Guidelines)

## Aturan Utama Ikon Tombol & CTA
1. **DILARANG MENGGUNAKAN ARROW (PANAH BERTANGKAI)**:
   - Jangan pernah menggunakan ikon panah dengan tangkai/garis horizontal atau vertikal (seperti `->`, `<-`, `M17 8l4 4m0 0l-4 4m4-4H3`, atau sejenisnya) pada SEMUA tombol, CTA, link, maupun navigasi carousel!
2. **WAJIB SELALU MENGGUNAKAN CHEVRON**:
   - Semua tombol, link aksi, tombol CTA ("Konsultasi", "Detail Mesin", "Lihat Semua", "Kembali"), dan kontrol slider/carousel WAJIB menggunakan ikon **Chevron** (`>` / `<` / `M9 5l7 7-7 7` / `polyline`).
   - Gunakan `stroke-width="2"` atau `2.5` dengan `stroke-linecap="round"` dan `stroke-linejoin="round"`.

## Estetika Desain ORIA
- **Monokrom Minimalis Industri**: Hitam (`#000000`), Putih (`#FFFFFF`), dan aksen abu-abu presisi.
- **Tipografi Tegas**: Heading menggunakan font display industrial tebal, kapitalisasi terstruktur.
- **Transisi Bersih**: Transisi slide masuk dari kanan ke kiri tanpa efek zoom/scale (langsung pada proporsi aslinya).
